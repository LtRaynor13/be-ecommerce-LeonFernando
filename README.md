# Backend Ecommerce - Leon Fernando

API REST desarrollada con Spring Boot y Java 17.

## Tecnologias
- Spring Boot
- Java 17
- Maven
- MySQL 8.4
- Docker
- Spring Data JPA
- Spring Security
- JWT

## Funcionalidades
- Registro e inicio de sesion.
- Autenticacion mediante JWT.
- CRUD de productos.
- DTO y servicios.
- Named Queries y JPQL.
- Configuracion CORS.
